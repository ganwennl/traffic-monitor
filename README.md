# TrafficMonitor 本地维护版 / Locally Maintained TrafficMonitor

我从 TrafficMonitor V1.86 修改维护的版本，用于在 Windows 上查看网速、CPU 和内存使用情况。当前维护 Windows x64 Lite，支持悬浮窗、任务栏显示、网卡选择和历史流量统计，更新由自己手动完成。

源码和工程在 `TrafficMonitor/`，构建说明见 `LOCAL_MAINTENANCE.md`，需要 Visual Studio 的 C++、MFC 和 Windows SDK 工具链。配置、皮肤和历史记录保存在本机。

原作者是 zhongyang219，上游项目为 [TrafficMonitor](https://github.com/zhongyang219/TrafficMonitor)。保留原 Anti-996 `LICENSE`、`LICENSE_CN`、第三方组件许可和版权声明。

## English

My maintained version of TrafficMonitor, based on V1.86, for viewing network speed, CPU usage and memory usage on Windows. The current target is Windows x64 Lite, with a floating window, taskbar display, adapter selection and traffic history. Updates are installed manually.

Source and project files are in `TrafficMonitor/`. See `LOCAL_MAINTENANCE.md` for build instructions using Visual Studio C++, MFC and the Windows SDK. Settings, skins and traffic history are stored locally.

The original author is zhongyang219, and the upstream project is [TrafficMonitor](https://github.com/zhongyang219/TrafficMonitor). The original Anti-996 `LICENSE`, `LICENSE_CN`, third-party licenses and copyright notices are retained.
